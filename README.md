# ising
Simple yet efficient Ising simulation.

## To run the simulation of 64x64 lattice with 10000 outer cycles and 10 frames per outer cycle:

```bash
./target/release/ising -l 64 --outer-cycles 10000 -t $t \
            --outer-per-frame 10 --png-frames "frames/f_"
```
The simulation will generate 1000 frames (due to ``--outer-per-frame 10``) in the `frames` directory (which must exits!);
they can be combined into a video using ffmpeg:

```bash
ffmpeg -framerate 30 -i frames/f_%06d.png -c:v libx264 -pix_fmt yuv420p out.mp4
```

The code compares the performance of two different implementations
 - naive Metropolis algorithm where a spin is selected randomly
 - the checkerboard sampling order where iterations goes over spins in a checkerboard pattern. 
   Besides being more efficient for parallelization, this version calls the random number generator only once per spin 
   flip attempt (for the Metropolis acceptance test). This version also uses a pre-computed table of Boltzmann factors for the acceptance test, which avoids exp() evaluations.

The second version is about 2 times faster than the first one for a 64x64 lattice.

## Included helper scripts:

- `run_isothermal.sh` : runs isothermal simulations for a range of temperatures
 - `make_movies.sh` : makes movies from frames generated by the `ising` app (from the `frames` directory)
 - `make_plots.py` : makes plots: energy over time, over temperature, CV etc. (requires `matplotlib`)
